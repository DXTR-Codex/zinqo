Nouveautés

Ce qui a changé dans les dernières versions de Zinqo. Le logiciel te propose lui-même chaque mise à jour.

Prochainement

Idées en cours, sans date
  • Zinqo en anglais, avec le choix de la langue à l'installation.
  • Piloter Zinqo depuis un assistant IA : créer et suivre ses clips en lui parlant.
  • Envoyer un clip sur son téléphone, même hors de chez soi.

Version 2.4.7

22/11/2026

  • Petites corrections d'affichage.

Version 2.4.5

22/11/2026

  • Activation par code à usage unique : l'auteur te donne un code, tu le colles, il se lie à ton PC (plus de code PC à envoyer).

Version 2.4.3

22/11/2026

  • Petites corrections d'affichage.

Version 2.4.2

22/11/2026

  • Le réglage « Canal test » (Avancé > Lancement) disparaît : les versions de test sont réservées à l'éditeur. Rien ne change pour tes mises à jour, qui restent automatiques.
  • Zinqo demande maintenant un code d'activation au premier lancement : il affiche ton code PC, à envoyer à l'auteur, qui te renvoie un code valable pour ce PC.

Version 2.4.1

22/11/2026

  • Onglet IA : quand tu enregistres ta clé Gemini, un compteur montre que la vérification avance (jusqu'à 1 minute si Google est chargé), et « dernière vérification » affiche bien l'heure de ce test.

Version 2.4.0

22/11/2026

  • L'onglet « iPhone » devient « Envoi » : les textes parlent de « téléphone » (iPhone ou Android), avec un bouton « Utiliser Google Drive » en plus. Le bouton « Sur mon téléphone » remplace « Sur mon iPhone » sur chaque clip. Les boutons de l'onglet Envoi et le bouton « Suivre » de l'onglet Veille ne se chevauchent plus.
